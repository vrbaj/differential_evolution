Citation and license
====================

License
-------

The project metadata currently declares the MIT license. A dedicated
``LICENSE`` file is not present in the repository and should be added if the
project is to be distributed formally.

Software citation
-----------------

There is currently no ``CITATION.cff`` file or formal software-paper citation
metadata in the repository.

Recommended next step
~~~~~~~~~~~~~~~~~~~~~

Add a ``CITATION.cff`` file containing:

* project title;
* author names and ORCID identifiers if desired;
* repository URL;
* version tag;
* release date;
* preferred software citation text.

Until then, cite the repository by URL and version or commit hash.
